This project involves performing comprehensive financial analysis, including Descriptive, Diagnostic, and Predictive modeling. The application utilizes Python, Scikit-learn, and Streamlit to provide actionable financial insights.

- **Model:** Logistic/Linear Regression model used with feature engineering.
- **Evaluation:** Model evaluated based on Accuracy, AUC, and other performance metrics.
